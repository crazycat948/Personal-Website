Fan's Weather

The Weather Searching Project is an interactive tool that uses the OpenWeather API to provide real-time weather information. Users can search for a city by name to view current weather conditions, including temperature, humidity, and more. The project delivers accurate and up-to-date data in a user-friendly interface, helping users stay informed about weather conditions in any city nationwide.

Fan's Pokemon

The Pokémon Search Website lets users explore Pokémon details using the Pokémon API. Users can search by name to view information like type, abilities, and weakness. A built-in feature analyzes type weaknesses using JavaScript, and a "Shiny Mode" toggle displays the shiny version of any Pokémon. The site offers an engaging and user-friendly experience for fans and trainers.
